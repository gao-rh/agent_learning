# AI 训练数据岗位面试问题清单

> 版本：2026-09-03 调研稿。本清单用于确定学习范围，不代表已经掌握，也不是任何一家公司的固定题库。

## 结论：这类面试到底在考什么

公开面经和当前 32 份 JD 交叉后，核心不是背某个框架的 API，而是能否完整回答：

> 数据从哪里来，怎样变成可信训练集，怎样被模型消费，怎样通过受控实验证明有效，以及这个过程中你本人真正完成了什么。

面试通常沿着六条线追问：

1. **项目真实性和 Ownership**：规模、本人职责、替代方案、失败、指标口径。
2. **训练数据方法**：来源、清洗、去重、配比、标注、合成、版本。
3. **数据效果闭环**：评测集、对照实验、Badcase、污染和数据贡献归因。
4. **模型与训练基础**：预训练、SFT、Preference/RL、Transformer、PyTorch。
5. **工程落地**：Pipeline、Spark/Ray、幂等、恢复、可观测、成本。
6. **岗位专项**：多模态，或 Code Agent 的轨迹、环境、沙箱和 verifier。

证据标记：

| 标记 | 含义 |
| --- | --- |
| `真实重复` | 至少两个独立第一人称相邻面经出现同类问题 |
| `真实单源` | 一个第一人称相邻面经明确出现 |
| `相邻重复` | 本地 Agent / 数据工程面经重复，但不是训练数据同岗 |
| `JD 推断` | 当前岗位职责强烈指向，尚无可靠同岗面经证明 |
| `项目推断` | 针对本人现有项目证据的必然追问 |

来源证据和链接见[面试资料来源索引](面试问题/来源索引.md)。

8. `JD 推断｜P0` 图像正常但文本错误、模态缺失、音画不同步时怎样识别？
9. `JD 推断｜P1` OCR 如何处理版面、阅读顺序、表格、公式和置信度？
10. `JD 推断｜P1` 视频如何切镜头、采帧、保留时序并减少相邻帧重复？
11. `JD 推断｜P1` 图像增强和文本扰动怎样保证语义标签不被破坏？
12. `真实重复｜P0` 如何证明某个多模态数据版本改善了目标能力？

## 十、Code Agent 数据、轨迹、环境与 Verifier 专项

这一组对 DeepSeek Code Agent、阿里 Agent 训练数据、腾讯 Agent 环境平台和面壁仿真环境岗位权重最高。除标记为真实的问题外，其余均为当前 JD 高概率推断，不是假称的 DeepSeek 原题。

1. `真实重复｜P0` 讲一个真实 Coding Agent 任务：它在哪里失败，你怎样验证代码而不是相信最终回答？
2. `真实单源｜P0` Coding Agent 日志如何按任务类型、thinking、工具调用、结果和执行效率分类打标？
3. `JD 推断｜P0` 一条可执行 Agent 任务应包含哪些字段：初始状态、工具、约束、终止条件和 verifier？
4. `JD 推断｜P0` Trajectory 中 observation、action、tool arguments、tool result、diff、reward、done 如何建模？
5. `真实单源 + JD｜P0` 如何把真实 Git 仓库问题构造成可重复运行的 RL Environment？
6. `真实重复｜P0` 为什么需要沙箱？Docker、依赖、网络、文件、权限、时钟和随机性如何隔离及 reset？
7. `真实单源 + JD｜P0` Agent 的 checkpoint、状态回滚和 trace replay 如何实现？
8. `JD 推断｜P0` 最终测试、编译、lint、过程行为和部分完成度如何组成 reward？
9. `JD 推断｜P0` 如何防止 Agent 修改测试、绕过验证器或利用环境漏洞进行 Reward Hacking？
10. `JD 推断｜P0` pass@k、重复运行、flaky test 和非确定性环境如何处理？
11. `JD 推断｜P0` “任务成功”是否等于“轨迹质量高”？偶然成功、冗余步骤和错误后恢复如何评价？
12. `真实重复｜P0` 如何区分模型问题、数据问题、工具问题、环境问题和 verifier 问题？
13. `JD 推断｜P0` 外部网页变化、依赖升级和服务失效时，如何保持任务可复现？
14. `JD 推断｜P1` 如何过滤死循环、重复轨迹、无效探索和失败 rollout？
15. `JD 推断｜P1` 长程任务的部分奖励、阶段 checkpoint 和过程评测如何设计？
16. `JD 推断｜P1` 如何批量调度数万条任务，管理 CPU/GPU/容器/浏览器和成本？
17. `真实重复｜P0` 线上 Badcase 如何转成专项任务、训练样本和回归评测闭环？
18. `真实单源｜P1` 多 Agent 的通信、异步、权限隔离、上下文遗忘和子 Agent 错误如何处理？

Code Agent 岗的真正区分项不是通用语料清洗，而是：

> 软件工程领域深度 + Agent 评测 + 可复现环境 + 自动 verifier + 从真实失败构造训练数据。

## 十一、针对本人遥感 + POI 项目的高风险追问

以下不是网络真题，而是把目标岗位的追问方式套到本人已有材料后，几乎必然出现的问题。回答前必须恢复原始证据，不能靠包装补空白。
