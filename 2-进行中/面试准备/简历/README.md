## 面试取材顺序

1. 实际投递版决定面试官看到了什么；未确认时明确采用哪个候选版本。
2. [项目准备](../项目准备/README.md)与当前口径决定能用哪些事实、个人贡献与数字。
3. [岗位准备](../岗位准备/README.md)组织该岗位要重点证明的能力；[能力资料](../资料/README.md)提供技术答案。

不要用旧简历中的数字或漂亮文案覆盖项目当前事实。两种方向可以调整篇幅与重点，不能增加未经确认的生产能力或个人贡献。
