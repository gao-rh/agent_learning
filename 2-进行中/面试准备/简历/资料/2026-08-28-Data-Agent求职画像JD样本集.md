## 核心 JD 卡

### 1. 字节跳动：Agent研发工程师（数据智能体）- 创新&中台

- **组织/场景**：创新与中台数据 BP；服务内容质量侧的数据智能产品。
- **工作主线**：参与需求分析、架构设计和编码；建设数据智能产品的 Agent 服务；推动基于 Agent 的数据产品架构创新。
- **数据侧要求**：明确出现语义层建设和评测体系，不只是通用聊天或知识问答。
- **Agent 侧要求**：Prompt Engineering、Multi-Agent、RAG，以及 Agent/RAG 的真实落地经验。
- **工程/业务要求**：能理解业务并抽象需求，具备平台开发、技术选型和方案落地能力；LangChain、Dify 属于加分项而不是岗位本体。
- **边界**：官网未写固定工作年限，也未明确 Text2SQL、指标口径校验或数据权限细节，面试时需进一步确认产品链路。

### 2. 腾讯：智能体应用技术算法工程师

- **组织/场景**：TEG 大数据（数据计算平台部）；面向数据分析、治理、检索和决策辅助。
- **完整链路**：自然语言问题 → 数据理解 → 分析推理 → 结果生成 → 决策辅助。
- **数据侧要求**：RAG、Text2SQL、知识图谱、语义层建模、复杂查询、跨表推理、多轮问答。
- **可信要求**：分别评估 SQL 正确率、业务口径准确性和数据安全合规，而不是只看 SQL 能否执行。
- **Agent 侧要求**：编排、工具调用、记忆、多智能体、动态规划、自适应执行、Harness/Loop Engineering。
- **工程侧要求**：Python、系统设计、工程交付、性能、可观测和评测体系；3 年以上工作经验。
- **画像意义**：这是本轮最适合用作“企业级 Data Agent 开发工程师”基准的 JD。

### 3. 腾讯：腾讯营销-高级数据产品agent算法工程师

- **组织/场景**：CDG 腾讯广告；面向多业务接入的数据产品 Agent。
- **Agent 主链路**：复杂推理链、任务规划、工具调用、状态管理。
- **数据与检索**：RAG、Context Engineering、Function Calling、向量库、图数据库、Text2SQL。
- **平台化要求**：配置化、插件化、可观测、高可用、可扩展和低接入成本。
- **效果与成本**：任务成功率、知识召回、响应延迟、推理成本和用户体验均进入优化目标。
- **算法要求**：包含 SFT/RL 和 LLM 评测，明显比一般 Agent 后端更偏算法；要求 3 年以上后端或算法经验，硕士优先、优秀本科可酌情考虑。
- **画像意义**：适合作为挑战岗样本，不能把其中的后训练要求误判为所有 Data Agent 岗位的通用门槛。

### 4. 美团：Agent工程师（商业智能）

- **组织/场景**：核心本地商业-基础研发平台；经营分析、营销投放、销售拓展和商业变现。
- **工作主线**：构建可用于真实商业经营的自主智能体，服务商户和内部员工，并参与商业经营新范式的定义。
- **规模信号**：官网列表写明涉及营销预算、广大商户和数万员工，说明岗位强调真实业务规模而不是 Demo。
- **当前可确认范围**：官方列表当前只展示两条职责，未展示完整任职要求；不采用第三方页面补齐为官网事实。
- **画像意义**：非常适合观察“懂业务的 Agent 工程师”，但标题中的“商业智能”不能自动等同于 Text2SQL 或传统 BI。

## 趋势与相邻样本

### 5. 腾讯云 DataBuddy-Agent研发专家

- 负责 Agent Runtime、上下文工程、记忆、自进化、可观测和评测。
- 将 Data Infra/AI Infra 与大数据场景结合，并建设底层图谱和知识挖掘体系。
- 要求 Java/Python/Go 中至少一种语言、系统功底、一定规模平台研发和运维经验；官网当前写 5 年以上。
- 这是平台/Runtime 路线的能力上限样本，不适合作为当前最低投递门槛。

### 6. 腾讯云 DataBuddy-大模型算法专家

- 围绕任务理解、数据问答、工具调用、任务执行和结果可信建立评测体系。
- 通过用户反馈、交互日志、执行结果、错误案例和高质量样本建设数据飞轮。
- 包含 SFT、偏好优化、RL、自动评测、人工评审、Case Benchmark 和回归测试。
- 要求能够从日志和失败案例完成问题归因、样本构造、模型优化和效果验证；官网当前写 5 年以上。
- 这是算法/评测路线的能力上限样本，不代表业务型 Data Agent 工程师都必须做后训练。

### 7. 蚂蚁集团 Agent研发工程师（度量方向）

- 核心仍是研发效能数据：指标管理、数据挖掘、在线报告、可视化、数据资产和治理。
- Agent 的作用是提升数据分析效率、洞察深度和覆盖面，并要求准确、可追溯。
- 要求 3–5 年数据研发经验，熟悉 Hadoop、Spark、MaxCompute、ETL、数据质量、数据治理、查询优化和数仓。
- 这是“数据研发 + Agent 使用/产品化”的迁移岗位，不是负责 Agent Loop、Tool Runtime 或 Text2SQL 核心系统的典型岗位。

## 本次关键问题

下一轮不应直接把七个岗位的要求做词频合并，而要先确定求职画像的主口径：

1. **业务型 Data Agent**：面向业务人员问数、经营分析和决策辅助。
2. **数据平台型 Data Agent**：面向数据开发、治理、数据资产和平台 Runtime。
3. **算法型 Data Agent**：面向评测、数据飞轮、后训练和模型效果优化。

这三类岗位共享 Agent 工程基础，但数据知识、项目证据和算法门槛不同。未经本人确认，不把任一类设为正式主线。
