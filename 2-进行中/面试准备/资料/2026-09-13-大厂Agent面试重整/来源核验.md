# 2026 大厂 Agent 面试准备：来源与筛选依据

核验日期：2026-09-13。返回[主阅读页](README.md)。本文记录筛选事实与边界，不是阅读任务清单。

## 这次与旧版有什么不同

旧版 195 题服务于跨岗位收集，混有传统后端、算法、HR、匿名雇主和日期不明的本地材料。它不能直接回答“今年大厂、以 Agent 为核心的岗位应该准备什么”。本轮不继承旧版的题频、置信度评级或公司偏好结论。

本轮主阅读页是 **8 份符合条件的官方 JD 驱动的参考题库**。公开面经用于独立审计；本轮未取得“面经原帖与具体 JD 一一对应，且全部满足筛选条件”的样本。因此，**严格匹配的岗位真题样本为 0，不发布真题频次排行，也不把相邻岗位问题冒充同岗真题。** 这表示证据链未闭合，不表示没有相关面经或这些公司不考 Agent。

## 筛选规则

| 维度 | 本轮规则 |
| --- | --- |
| 年份 | 面经限 2026 年，优先 7—9 月；面试日与发帖日分开。JD 采用今年的官方发布或明确更新记录，二者分开标注；发现日、抓取日不冒充发布时间。 |
| 公司 | 以国内大型互联网公司为范围。本轮通过正文与日期核验的核心 JD 来自腾讯、字节、百度。未声称覆盖所有大厂；匿名雇主、中小厂不进入主依据。 |
| Agent 为主 | 先看工作职责。操作性判定为：至少约四分之三的独立职责直接围绕 Agent 产品、运行、工具、上下文、评测或改进；同时检查主要交付物。比例是文本人工归类，不是实际工时占比。 |
| 不偏传统后端 | 不以数据库、中间件、网络、微服务、Kubernetes、资源调度为主要交付物。职位分类标“后端”不自动排除；Agent 失败恢复和工具幂等仍属于核心工程问题。 |
| 招聘层级 | 社招优先；明确标出校招。实习不进入本轮主依据；专家岗只补能力上限，不用它的全部要求设定入门门槛。 |
| 题目性质 | JD 说明工作要求，不能证明某题实际出现。主阅读页题目、短答、追问和优先级均为 Codex 综合设计。 |
| 文章年份 | 阅读拓展优先采用 2026 年署期的一手文章。机制核对使用当日官方文档，未标发布日期的动态文档不包装成“2026 年新文章”，也不计入岗位或面经样本。 |

## 覆盖边界与后续维护规则

- 核心样本为 8 份官方 JD，3 家公司；7 份官方日期在 2026 年 7 月以后，另 1 份为 2 月。腾讯样本较多，不能视为整个大厂市场的均匀抽样。
- 没有足够证据支持“字节最爱问 X、阿里必考 Y”或“这些题覆盖面试 95%”。优先级来自符合范围的职责相关性、知识依赖与准备复用度，不是伪装成统计的主观分数。
- 新资料只有改变核心题、补上明显知识缺口或完成严格的面经/JD 对应，才进入主阅读页；单纯多一家公司、多一种同义问法，留在核验层即可。
- 旧 195 题和阅读地图继续保存原文，退出这次的默认阅读入口；本轮不删除历史、不读取本人面试转录、不改掌握状态。
