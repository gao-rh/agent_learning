3. 使用 `$interview-prep` 组织本次重点；先复用已有答案，只补岗位差异、事实缺口与新的追问。

## 每次新增内容先决定归属

| 新内容 | 更新位置 |
| --- | --- |
| 同一个概念的新解释、纠错或边界 | 能力资料索引指定的主文档和原章节 |
| 同一个项目的新事实或个人贡献 | 对应项目手册、原始补充记录与当前口径表 |
| 用户对某题的口述或确认 | 已有回答位置，区分原话、AI 候选和已采用稿 |
| 同一岗位的新轮次、JD 变化与关注点 | 已有岗位档案／岗位索引中的该岗位条目 |
| 新岗位，但可以复用现有技术内容 | 先在岗位索引加条目；确有持续资料需要再建轻量档案 |
| 新能力主题，现有主文档无法合理承接 | 新增一个稳定主题主文档并登记入口 |

不要因为日期变化、会话更换或追问几道题就另起整套材料。新的主文档先说明现有材料为什么无法承接、复用了哪些内容；保留旧材料独有证据，不能用简短摘要覆盖原文。
