## 题目

在 Agent 系统里，模型会生成一组工具调用。请实现：

```python
def execute_calls(calls, tools):
    """
    calls 示例：
    [
        {"id": "c1", "name": "search", "args": {"query": "AI Native"}},
        {"id": "c1", "name": "search", "args": {"query": "AI Native"}},
        {"id": "c2", "name": "missing_tool", "args": {}}
    ]

    tools 是工具名到函数的映射：
    {
        "search": search,
        "calculate": calculate
    }

    返回与 calls 顺序一致的结果：
    [
        {"id": "c1", "ok": True,  "value": ...},
        {"id": "c1", "ok": True,  "value": ...},
        {"id": "c2", "ok": False, "error": "unknown tool"}
    ]
    """
```

要求：

1. 只能调用 tools 中存在的工具。
2. 相同 id 最多实际执行一次，后续重复调用复用第一次结果。
3. 工具抛出异常时转成失败结果，不能影响后续调用。
4. 返回顺序必须与输入一致。
