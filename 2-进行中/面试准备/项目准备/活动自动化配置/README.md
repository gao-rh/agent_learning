# 活动自动化配置

> 状态：已有第一轮项目素材，等待单独复盘。当前内容不是正式简历定稿。

## 项目定位

- 面向场景险运营的活动配置 Agent，将自然语言业务诉求衔接到营销平台的活动类型、模板和参数。
- 底层十余类配置 Skill、Workflow 和营销平台能力由平台提供。
- 用户本人的核心贡献是业务意图、保险规则与平台配置能力之间的 Agent 编排和衔接。
- 配置生成后由运营人工确认再生效，保留人工确认边界。

## 当前已知效果

- 覆盖约 20–30 名运营，其中约 5–10 人高频使用。
- 日均约 10 个活动配置；原流程约 1 小时来自运营反馈，Agent 十几分钟来自系统时长数据。
- AI 看板采用效果不佳，真实需求更集中在快速、正确地完成配置。
