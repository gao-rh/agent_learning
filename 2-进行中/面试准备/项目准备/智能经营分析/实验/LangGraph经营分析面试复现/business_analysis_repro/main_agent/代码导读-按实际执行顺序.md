## 先看整条调用线

从命令行启动时，Python 会先处理 import、类和函数定义。下面从应用入口开始追踪有意义的调用；遇到函数调用就进入，返回后回到原来的位置。第一遍不用展开库内部源码。

```text
__main__.py 的 main()
└─ runtime.execute()
   ├─ 打开 SQLite、创建 Trace
   ├─ KimiModel()                  创建客户端，此时还没请求模型
   ├─ build_graph()                注册节点、连接边、编译图
   ├─ initial_state()              创建这次任务的初始数据
   └─ 迭代 graph.stream()          从这里开始由 LangGraph 调用节点
      ├─ understand_request       Kimi 提议 → 代码查指标配置、算日期 → 更新 task
      ├─ route_understanding      代码返回 run_analysis
      ├─ run_analysis
      │  └─ analysis_agent()
      │     ├─ query_agent()      取本期数据
      │     ├─ query_agent()      取前期数据
      │     └─ Python 计算        差额、变动率、渠道变化 → 更新 result
      ├─ compose_reply            Kimi 写草稿 → 更新 draft_reply
      ├─ validate_reply           第一次被代码检查拒绝 → 更新 validation
      ├─ route_validation         代码返回 compose_reply
      ├─ compose_reply            Kimi 根据反馈重写
      ├─ validate_reply           代码检查通过 → Kimi 复核 → status=completed

回到 main()，打印结果并退出
```

`route_understanding`、`route_validation` 是条件边调用的普通函数，不是额外注册的节点。图里有 7 个节点，但本例只经过其中 4 种节点，其中 2 种各执行了两次。

| 顺序 | 节点 | 本轮是否调用 Kimi |
