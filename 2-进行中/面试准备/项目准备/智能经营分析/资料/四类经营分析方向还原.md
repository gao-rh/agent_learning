# 四类经营分析方向还原

> 状态：基于原始资料、真实问题、WBR 样例和方法文档还原。2026-09-08 用户确认第四类为商户分析，包含原用户留存；留存以外的子方法及完整归因链路仍待补充。以下指标与方法的还原不自动等于全部已发布。

## 一句话结论

这四类分析并不是四种相互独立的算法，而是从不同位置回答场景险经营问题：

```text
渠道带来新增投保商户
→ 商户签约、留存或退出
→ 形成商户渗透和订单渗透
→ 最终共同影响保费结果
```

这是帮助记忆的业务关系，不代表所有指标之间都能直接用一条公式连接。

| 分析方向 | 主要回答什么 | 当前可恢复程度 |
| --- | --- | --- |
| 保费 | 实际保费与目标差多少，为什么未达标或为什么发生变化 | 方法较完整 |
| 渗透率 | 当前渗透水平和趋势怎样，为什么变化或与其他渗透率背离 | 方法较完整 |
| 渠道归因 | 加入商户数为什么下降，问题来自哪个渠道、漏斗环节和 source | 方法最完整 |
| 商户分析（包含原用户留存归因） | 商户留存、退出及其他商户表现分析 | 对象与包含关系已确认，完整方法待补 |

## 一、保费分析

### 它主要分析什么

保费分析不是只查“保费是多少”，而是围绕两个经营问题展开：

1. 当前实际保费相对目标的达成情况怎样；
2. 保费发生变化或未达目标，主要是单均保费、订单渗透率还是订单基数造成的。

### 主要分析链路

```text
确认险种、时间和目标
→ 查看实际保费、目标、达成率和 Gap
→ 按 P = A × R × Q 拆解
   ├─ A：单均保费
   ├─ R：订单渗透率
   └─ Q：订单基数
→ 用 Shapley 量化三个因子的贡献
→ 必要时再按险种、商户、新老商、城市或业务线下拆
→ 输出主因、拉动项和拖累项
```

不同险种的订单基数口径不完全一样：放心吃和准时宝的材料使用非取消订单量，取消险使用全量订单量。正式面试表达前仍应以最终生产指标定义为准。

### 它能回答的典型问题

- 26 年 7 月放心吃总保费多少？
- 只看下沉城市的放心吃保费是多少？
- 2025 年入驻商户和此前入驻商户分别贡献了多少保费？
- 今天保费为什么变化这么多？
- 本月保费为什么没有完成目标？

前两类问题偏查数和维度过滤；后三类才进入结构、变化或目标 Gap 分析。

## 二、渗透率分析

### 它主要分析什么

渗透率分析回答的不是一个统一指标，而是一组覆盖程度问题：当前投保覆盖到多少订单或商户、趋势怎样、是否达到目标、为什么变化，以及不同渗透率为什么出现背离。

现有材料至少涉及：

- 订单渗透率；
- 商户渗透率；
- 可投保订单占比；
- 可投保订单渗透率；
- 商家付费和平台采购等不同口径。

### 主要分析链路

```text
确认标准渗透率指标及分子、分母
→ 确认时间粒度和比较基准
→ 查看当前值、趋势、同比/环比或目标 Gap
→ 拆分分子与分母的变化
→ 按指标关系继续拆解
→ 必要时按新老商、商户类型、品类、城市、配送方式等维度下拆
→ 对照相关渗透率，解释同向、反向或背离
```

已有两类直接拆解关系：

```text
餐饮订单渗透率
= 可投保订单占比 × 可投保订单渗透率

商户渗透率
= 活跃在保商户 ÷ 外卖活跃商户
```

具体指标必须使用各自的正式分子、分母，不能把一个公式套给所有渗透率。

### 它能回答的典型问题

- 存量三险种的商户渗透率半年内有什么变化？
- 再交叉看订单渗透率，两者怎样变化？
- 准时宝新商近两年渗透率趋势怎样，并按商户类型、城市类型、主营品类和配送方式交叉观察？
- 准时宝商户渗透率持续上升，商家付费订单渗透率却下降，为什么？
- 哪些低渗透 KA 商户贡献了较多订单？

## 三、渠道归因

### 它主要分析什么

这里的渠道归因，更准确地说是场景险的流量渠道和获客归因。核心结果指标是“加入商户数”：当加入商户数下降时，定位下降来自哪个一级渠道、二级渠道、漏斗环节和具体 source。

它不是泛化的营销归因，也不是直接解释保费的所有变化。

### 主要分析链路

```text
全渠道加入商户数是否真的下降
→ 一级渠道贡献分析
→ 主因一级渠道下的二级渠道贡献分析
→ 主因二级渠道的流量漏斗分析
→ source / 资源位定位
→ 输出运营排查和行动建议
```

历史材料定义的流量链路为：

```text
外部入口曝光 UV
→ 外部入口点击 UV
→ 详情页曝光
→ 详情页点击
→ 加入商户数
```

配套观察外部入口点击率、CTR、跳转成功率、CVR 和到端转化率。周期比率应由周期分子汇总除以周期分母汇总，不能直接平均每天的比率。

### 它能回答的典型问题

- 为什么钱包渠道每周都在下降？
- 是流量下降、新加入商户减少、CTR/CVR 变化，还是商户类型结构变化？
- 外卖商家的新注册商户有没有变化？
- 今天某险种加入商户数下降，主要是哪个渠道和哪个漏斗环节导致的？

## 四、商户分析（包含原“用户留存归因”）

### 已确认的分析对象与材料还原

用户于 2026-09-08 明确，这里的用户就是商户，用户留存属于商户分析，且商户分析还包括留存以外的内容。现有 WBR 和项目总结可还原以下商户生命周期观察点，完整方法仍待补充：

```text
新增投保商户
→ 投保后当日留存
→ 新商签约后留存
→ 老商签约后留存
→ 主动退出 / 被动退出
```

当前统一名称为“商户分析”；“商户留存与退出分析”可描述其中一部分，不能将整个专题缩窄为仅做留存。

### 已能确认的观察指标

- 新增投保商户数；
- 投保后当日留存情况；
- 新商签约后留存率；
- 老商签约后留存率；
- 退出商户数；
- 主动退出与被动退出。

### 可以合理推断的分析问题

- 新增投保商户为什么下降？
- 新商或老商的签约后留存率为什么下降？
- 退出商户为什么增加，主要是主动退出还是被动退出？
- 变化集中在哪类商户、哪个险种或哪个生命周期阶段？

以上是根据指标结构推导出的分析问题，不等于已经找到真实生产问句或完整 Skill 方法。
