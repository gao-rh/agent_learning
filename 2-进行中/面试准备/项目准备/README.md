## 组织原则

- 每个项目独立保存背景、时间线、架构、个人贡献、问题—解法、效果、失败和证据边界。
- 简历 bullet、项目长答案和追问题库从项目事实源派生，不与原始口述混写。
- 涉及公司内部项目时，只保存脱敏后的个人复盘，不复制代码、真实业务数据、内部 Prompt、密钥或敏感文档。
- 形成简历短版时，只把结果写入“简历”专项；本目录继续作为上游事实源。
