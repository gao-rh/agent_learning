# 常见问题回答准备

> 《技术八股》《综合面试问题》是历史准备素材，用户说明未经过系统人工教研，完整性和正确性未获整体确认。保留两个入口及候选池用于持续审校，不作为标准答案或能力范围。
>
> 知识参考、用户原话与已采用表达按正文标记区分；个人表述已确认不等于技术解释正确，已有资料也不代表本人已掌握。按本次需要核查、纠错、补充和改善讲解，不要求每次重审全库。

| 文件 | 当前内容 | 更新方式 |
| --- | --- | --- |
| [技术八股](技术八股.md) | 现有 81 题数仓与大数据组件参考答案 | 相同主题补原章节；其他技术方向按[能力资料索引](../资料/README.md)定位，不在此重复抄一套 |
| [综合面试问题](综合面试问题.md) | 离职原因、AI Coding 等已有个人素材与整理稿 | 保留原话；修改含义或采用候选稿按用户确认处理 |
| [AI 候选池](AI草案-候选问题清单/README.md) | 尚未确认需要准备的综合问题 | 候选与已采用内容分开；不因 AI 建议就自动升级状态 |

具体项目的架构、难点、个人贡献和效果进入[项目准备](../项目准备/README.md)。既有 AI 数据专项的项目口述与题号继续保存在[原专项档案](../AI数据面试准备.md)，按需引用。

准备本次面试时，从岗位与外部证据判断需要的能力，再到[岗位索引](../岗位准备/README.md)与[能力资料](../资料/README.md)定位候选素材；审校后再使用，不把一个历史专项的顺序当作所有岗位的默认路线。

新知识解释、新个人口述和新岗位追问先定位已有位置，再补差异。旧宽范围题库可在[历史归档](../../../5-归档/面试准备旧清单/README.md)追溯，不是本次的默认题目清单。
