### 职位名称

AI数据研发工程师

### 职位详情标签

- Java
- 要求数据开发经验
- 数据建模经验
- Clickhouse
- 非外包类
- 实时数仓开发经验
- Spark
- 数据平台开发经验
- 数据仓库开发经验
- Flink
- 数据治理经验
- Python

### 职位描述

1. 主导面向Agent的新型数据语义层架构设计与落地，推动数据资产从数据表向智能体可理解、可调用、可推理的消费模式演进；

2. 负责端到端数据建模设计与开发交付，基于流批一体架构（Flink + Spark + Paimon）实现业务模型的统一构建与服务；

3. 负责数据质量治理与链路稳定性保障，建立覆盖全链路的监控告警、血缘追踪，确保关键数据任务满足SLA要求；

### 职位要求

1. 技术基础扎实：熟练掌握 Java、Python、SQL 中一种或多种数据处理语言，具备良好的编码习惯与工程化思维；

2. 数据处理与平台经验：熟悉主流大数据技术栈（如 Hadoop、Spark、Flink、Paimon、MaxCompute 等），有实时/离线ETL开发、湖仓一体建设、流批融合项目经验者优先；

3. 数据资产意识强：对元数据管理、数据血缘、数据标准、质量规则等数据治理核心领域有深入理解或实战经验，能将治理能力产品化、自动化；

4. 业务理解与沟通能力：具备优秀的逻辑抽象与业务敏感度，能够精准识别需求本质，并将其转化为可落地的数据模型与服务接口；

5. 学习与适应能力强：对 LLM + Data、AI Agent、语义建模等前沿方向有浓厚兴趣，能快速掌握新技术并在复杂系统中验证落地；

6. 团队协作精神：积极主动、责任心强，具备良好的跨团队协作意识与项目推动力，能在多角色协同中达成目标；

7. 学历背景：本科及以上学历，计算机、数学、统计学、信息管理或相关专业优先。
