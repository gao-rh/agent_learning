## T1｜用户运营技术：AI 应用开发一面

[阅读原帖：淘天日常实习生-用户运营技术-AI应用开发工程师一面凉经](https://www.nowcoder.com/feed/main/detail/5dca9d9dd8284cc4aada23b9f0c20f15)

作者：HELIOSA。页面时间：08-18 22:19（已编辑）。招聘类型：日常实习。关联：同公司、同用户运营技术方向，与你的社招不同。

**用户指定保留的重点面经。** 问题索引：

- Agent 做什么、如何执行；读写代码仓库与提交代码怎样串起来。
- 新需求进入后，模型产物与工具操作如何逐步衔接。
- 知识来源、代码索引、RAG 切块不完整时的处理。
- Harness、ReAct 和工具调用各自解决什么问题。
- Java 类加载与内存、线程池与锁、集合结构和缓存。

作者另提到在线 Agent 笔试。该流程只代表这次实习自述，不据此推断你的面试形式。

**Codex 分析：** 有参考价值的是连续追问实现过程，而不只问名词。你的项目可以用来讨论执行链路、状态、工具输入输出和错误处理；后端基础仍是独立考察部分。
