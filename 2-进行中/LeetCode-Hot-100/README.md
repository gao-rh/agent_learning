## 学习问题状态与验收

| 状态 | 含义 |
| --- | --- |
| `待继续` | 尚未独立完成，或仍无法解释关键不变量 |
| `待验证` | 已借助提示或题解写出，需要在 D+1 / D+3 / D+7 盲写验证 |
| `已理解` | 不看题解独立写出，并能解释思路、复杂度、边界条件和为什么正确 |

单题只有同时满足以下条件，才能从 `待验证` 转为 `已理解`：

1. 在约 25 分钟内独立完成核心实现；
2. 能说清暴力解法为什么慢、当前解法用什么信息避免重复计算；
3. 能给出时间和空间复杂度；
4. 至少覆盖空输入、重复元素、极端长度等相关边界；
5. 至少完成一次隔日盲写，不靠记忆具体代码行。

## 学习路线

采用“框架先行，但立刻用 Hot 100 验证”的方式：

1. 用 5—10 分钟理解当前题型的核心数据结构或不变量；
2. 先独立预测并尝试题目，不先看完整题解；
3. 卡住 12—15 分钟后，只读对应框架或提示，再重新实现；
4. 当天口述，D+1 / D+3 / D+7 复习；
5. 每周按真实状态调整，不为了题数把 `待验证` 写成 `已理解`。

## 每日 1～2 小时闭环

- 10～15 分钟：复习一道到期题，口述核心不变量并盲写关键代码；
- 40～60 分钟：学习并实现 1～2 道同类新题；
- 10～15 分钟：记录错误、复杂度、边界条件和下次复习日期；
- 当天投入接近 2 小时时，再增加 30 分钟补题或做第二道题，不预先固定必须完成的题数。

若当天只能真正完成一道题，则保留一道，不追求凑数。
