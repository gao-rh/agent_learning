### 283. 移动零：用户原始实现

> 仅将消息中的 HTML 空格实体还原为普通缩进，保留变量名和算法结构。

```python
class Solution(object):
    def moveZeroes(self, nums):
        """
        :type nums: List[int]
        :rtype: None Do not return anything, modify nums in-place instead.
        """
        v = 0
        l = len(nums)
        for i in range(l):
            if nums[i] != 0:
                nums[v] = nums[i]
                v += 1
        while v < l:
            nums[v] = 0
            v += 1
```

class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        pre = None
        curr = head
        while curr is not None:
            nxt = curr.next
            curr.next = pre
            pre = curr
            curr = nxt
        return pre
```

class Solution(object):
    def mergeTwoLists(self, list1, list2):
        """
        :type list1: Optional[ListNode]
        :type list2: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        dummy_node = ListNode(0)
        node = dummy_node
        while node is not None:
            if list2 is None:
                node.next = list1
                return dummy_node.next
            if list1 is None:
                node.next = list2
                return dummy_node.next
            if list1.val < list2.val:
                node.next = list1
                list1 = list1.next
                node = node.next
            else:
                node.next = list2
                list2 = list2.next
                node = node.next
```

```python
class Solution(object):
    def getIntersectionNode(self, headA, headB):
        """
        :type headA: ListNode
        :type headB: ListNode
        :rtype: ListNode
        """
        if headA is None or headB is None:
            return None
        hA = headA
        hB = headB
        while hA != hB:
            hA = hA.next if hA is not None else headB
            hB = hB.next if hB is not None else headA
        return hA
```

### 283. 移动零：代码审查

- 结论：实现正确。已验证标准示例、全零、无零、单元素、包含负数和空数组共 7 组用例，均得到预期原地修改结果，返回值为 `None`。
- 时间复杂度：`O(n)`。两个循环都是线性的，顺序执行应相加而不是相乘。
- 额外空间复杂度：`O(1)`。
- 稳定性：非零元素按原遍历顺序写入，所以相对顺序保持不变。

第一轮扫描的严格不变量是：处理索引 `i` 之前，`nums[0:v]` 恰好保存原数组已扫描部分中的所有非零元素，且顺序不变；同时始终有 `v <= i`，所以 `nums[v] = nums[i]` 不会覆盖尚未扫描的元素。

第一轮结束后，`nums[v:]` 不保证已经是零。例如输入 `[0, 1, 0, 3, 12]`，第一轮结束时可能是 `[1, 3, 12, 3, 12]`，因此第二个 `while` 不是多余的，它负责把残留旧值清零。

可读性上，`v` 可以改名为 `write`，`l` 可以改名为 `n`，并写成 `if nums[i] != 0:`；这些只是命名和 Python 风格建议，不影响算法正确性。

语句顺序不能随意交换。必须先执行 `nxt = curr.next`，再执行 `curr.next = pre`；否则一旦改写 `curr.next`，就失去了继续访问原链表后缀的入口。

### 160. 相交链表：代码审查

- 结论：在题目给定的 `ListNode` 定义下实现正确。已验证标准相交、无交点、值相同但节点不同、同一头节点、仅尾节点相交、单空和双空共 7 类边界；返回结果均为预期的节点对象，输入链表指向未被修改。
- 时间复杂度：`O(m + n)`；两个指针各自最多走完 `A + B` 或 `B + A` 两段路径。
- 额外空间复杂度：`O(1)`。
- 空链表：开头的提前返回正确，但不是必需的；双指针循环本身也能处理空输入。

两个指针第一次走到末尾后交换起点，使 `hA` 走过的总路径为 `A + B`，`hB` 走过的总路径为 `B + A`，从而抵消两个链表独有前缀的长度差。若存在公共尾部，它们会在第一个公共节点相遇；若不存在，则最终同时为 `None`。

相交要求比较节点身份，不是节点值。当前 `ListNode` 没有自定义值相等规则，因此 `hA != hB` 在本题环境中能正确工作；但 Python 中更严格、语义更清晰的写法是 `while hA is not hB:`。若节点类将 `==` 定义成只比较 `val`，当前写法会把两个值相同但实际不同的节点误判为相交。

先只验证一个问题：设链表 A 的独有前缀长度为 `a`，链表 B 的独有前缀长度为 `b`，公共尾部长度为 `c`；两个指针分别走过怎样的路径，为什么最终能在第一个公共节点对齐？

用户回答：“都走了 A 加 B 减 C，所以是相等。”

口述验证结论：核心正确。若 `|A| = a + c`、`|B| = b + c`，则 `hA` 走完 A 后再走 B 的独有前缀，`hB` 走完 B 后再走 A 的独有前缀；两者经过的非空路径长度都是 `a + b + c = |A| + |B| - c`。严格按当前代码的指针更新次数计数时，两边还都会经过一次 `None`，因此同时多一次跳转，不影响两条路径等长或最终对齐的结论。
