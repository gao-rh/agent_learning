## Codex 反馈

### `deque`：可以从两端操作的双端队列

`deque` 来自 Python 的 `collections` 模块，名称是 **double-ended queue（双端队列）** 的缩写。可以把它想象成一条左右两端都开口的通道：

```text
左端  <-  [1, 2, 3]  ->  右端
```

它本身不是“只能当栈”或“只能当普通队列”的结构。因为左右两端都能快速添加和删除，所以取决于方法组合：

| 用法 | 入元素 | 出元素 | 顺序 |
| --- | --- | --- | --- |
| 普通队列 | `append(x)` 从右端加入 | `popleft()` 从左端取出 | FIFO，先进先出 |
| 栈 | `append(x)` 从右端加入 | `pop()` 从右端取出 | LIFO，后进先出 |

Python 官方文档把 `deque` 定义为栈和队列的泛化，并说明两端添加、弹出都具有近似 `O(1)` 性能：[collections.deque](https://docs.python.org/3/library/collections.html#collections.deque)。

### 栈、队列、双端队列不等于链表

栈、队列、双端队列首先是**抽象数据类型**：它们规定允许哪些操作以及元素以什么顺序出来，并不规定底层必须是数组还是链表。

| 抽象结构 | 常见数组实现 | 常见链表实现 | 关键要求 |
| --- | --- | --- | --- |
| 栈 | 动态数组，末尾作为栈顶 | 单链表，头节点作为栈顶 | 同一端 `push/pop` |
| 队列 | 环形数组/循环缓冲区 | 带 `head`、`tail` 的单链表 | 一端入队、另一端出队 |
| 双端队列 | 环形数组/分块数组 | 带头尾指针的双向链表 | 两端都能快速增删 |

它们都可以用链表实现，但工程实现经常使用数组或数组与链表的混合结构。

#### 为什么普通数组队列要做成环形数组

如果每次从普通数组索引 `0` 删除元素，后面的元素需要整体搬移，成本是 `O(n)`。环形数组只移动头尾下标，不搬动所有元素，因此两端操作通常是 `O(1)`；容量不足时才需要扩容。

#### 为什么链表队列需要同时保存头尾指针

单链表队列通常这样设计：

```text
出队 head -> [1] -> [2] -> [3] <- tail 入队
```

- `head` 删除最早元素：`O(1)`。
- `tail` 添加新元素：`O(1)`。
- 如果没有 `tail`，每次入队都要从头走到链表末尾，会退化为 `O(n)`。

#### 双端队列为什么常用双向链表或环形缓冲区

双端队列要求左右两端都能删除。普通单链表虽然能 `O(1)` 删除头节点，但删除尾节点时无法直接找到它的前驱，通常要遍历。双向链表保存 `prev/next`，或者环形缓冲区维护左右下标，都能支持两端快速操作。

#### 当前 Python `deque` 的实际实现

以 CPython 当前实现为例，`collections.deque` 不是“每个元素一个节点”的朴素双向链表，而是**由固定长度数组块组成的双向链表**。这样兼顾两端增删、减少逐元素指针和内存分配开销，并改善局部性：[CPython `_collectionsmodule.c`](https://github.com/python/cpython/blob/main/Modules/_collectionsmodule.c)。这是实现细节；做算法题时只需要依赖公开的两端近似 `O(1)` 操作。

#### `deque` 的默认大小与扩容

需要区分三个概念：

1. **当前逻辑长度**：`deque()` 刚创建时 `len(q) == 0`。
2. **公开的最大长度**：默认 `q.maxlen is None`，表示没有人为设置上限，会按需要增长直到受到可用内存限制；不是“默认最多 64 个”。
3. **内部块大小**：当前 CPython 源码的 `BLOCKLEN` 是 `64`，表示一个内部数组块有 64 个指针槽位。这是实现细节，不属于 Python API 的稳定保证。

当前 CPython 的增长方式不是申请一个更大的连续数组并复制全部元素，而是：

```text
初始块满了
    ↓
[block 1] <-> [new block]
```

- 右端 `append` 没有槽位时，在右侧申请并链接一个新块。
- 左端 `appendleft` 没有槽位时，在左侧申请并链接一个新块。
- 已有元素不需要整体搬移，因此两端添加保持近似 `O(1)`。
- 某个端点的块被弹空后，该块可以被释放或放进内部空闲块缓存，供后续复用。

如果显式创建有界 deque：

```python
q = deque(maxlen=3)
q.extend([1, 2, 3])
q.append(4)
```

它不会扩成 4，而是从相反一端自动丢弃最旧元素，最终为 `[2, 3, 4]`。`appendleft` 加满时则会从右端丢弃。

对于其他常见实现：

- 链表没有“数组容量”和整体扩容，每插入一个元素就申请节点或复用节点。
- 动态数组/环形数组的初始容量没有统一标准；满时常见做法是扩大到约 `1.5` 倍或 `2` 倍，再把现有元素复制到新数组。这种扩容单次是 `O(n)`，但摊销后追加通常仍为 `O(1)`。

### 四个最常用的端点操作

假设：

```python
from collections import deque

q = deque([1, 2, 3])
# 左端 <- [1, 2, 3] -> 右端
```

| 方法 | 作用 | 示例结果 |
| --- | --- | --- |
| `q.append(4)` | 右端加入 | `[1, 2, 3, 4]` |
| `q.appendleft(0)` | 左端加入 | `[0, 1, 2, 3, 4]` |
| `q.pop()` | 删除并返回右端元素 | 返回 `4` |
| `q.popleft()` | 删除并返回左端元素 | 返回 `0` |

`pop()` 和 `popleft()` 都会同时完成两件事：**取出元素并从 deque 中删除它**。空 deque 调用它们会抛出 `IndexError`。

### 111 中为什么是队列

```python
q = deque([root])
node = q.popleft()
q.append(node.left)
q.append(node.right)
```

- 根节点先从右端进入。
- 每次从左端取出最早进入的节点。
- 新发现的子节点继续放到右端。

所以这是 `append + popleft` 组成的 FIFO 队列：上一层先入队的节点会在下一层节点之前出队，正好支持 BFS 按层遍历。

### 其他常见能力

- `len(q)`：当前元素数量。
- `q[0]` / `q[-1]`：查看最左/最右元素，不删除。
- `q.extend(iterable)`：从右端批量添加。
- `q.extendleft(iterable)`：逐个从左端添加，最终顺序会反转。
- `q.clear()`：清空。
- `q.rotate(n)`：整体向右轮转 `n` 步；负数表示向左轮转。
- `deque(maxlen=k)`：创建最多保留 `k` 个元素的有界 deque；满后继续添加会自动丢弃另一端元素。

算法题中优先记住前四个端点操作即可。`deque` 适合频繁操作两端，但不适合频繁随机访问中间位置；官方文档说明两端索引是 `O(1)`，中间索引会退化为 `O(n)`。

### 正确的核心

- 空树返回 `0`，边界正确。
- 使用 `l = len(q)` 固定本层节点数，保证一轮 `for` 只处理同一层。
- 叶子判断写成 `node.left is None and node.right is None`，这一点正确；只有一个孩子的节点不能当作叶子。
- BFS 从浅到深处理节点，因此第一次遇到的叶子位于最浅层，可以直接返回当前深度。

### 需要修改的循环条件

`while q is not None` 判断的是 deque 对象是否为 `None`。`q` 创建后一直是一个 deque 对象，即使里面没有元素，这个条件仍然为真。

本题在非空有限二叉树中最终一定会遇到叶子并提前 `return`，所以当前写法通常仍能通过；但它没有准确表达“队列非空时继续循环”。应改为：

```python
while q:
```

同时，`lens` 更适合命名为 `depth`。如果提交代码顶部没有其他导入，还需要：

```python
from collections import deque
```

整理后的核心实现：

```python
from collections import deque

class Solution(object):
    def minDepth(self, root):
        if root is None:
            return 0

        q = deque([root])
        depth = 1

        while q:
            for _ in range(len(q)):
                node = q.popleft()

                if node.left is None and node.right is None:
                    return depth

                if node.left is not None:
                    q.append(node.left)
                if node.right is not None:
                    q.append(node.right)

            depth += 1
```

### 复杂度

- 时间复杂度：最坏 `O(n)`，每个节点最多入队、出队一次。
- 空间复杂度：`O(w)`，`w` 是二叉树最大层宽；最坏为 `O(n)`。
