## 后续怎么使用原件

阅读从 [agent-loop.ts](本地资料/pi/packages/agent/src/agent-loop.ts) 与 [EventStream](本地资料/pi/packages/ai/src/utils/event-stream.ts) 开始。

不要直接在这份固定原件上做练习、升级或安装第三方扩展。正式开始运行时先建立独立实验副本；小型机制实验可置于本主题 `实验/`，完整产品复现必须另建仓库与开发任务。

以下为**后续候选步骤，未执行**：

1. 检查原件仍处于固定提交、无改动。
2. 在实验副本按锁文件执行 `npm ci --ignore-scripts`，先检查当时的依赖安装结果；不自动放开生命周期脚本。
3. 按上游说明区分模型数据补齐与编译；`build:offline` 使用已有模型数据，但不表示缺失 npm 依赖也能离线安装。
4. 无真实模型验收先使用 faux provider 或明确的 mock，用上游 `test.sh` 所示隔离策略；不要直接运行可能读到现有凭据的全量测试。
5. 在独立、只含合成文件的目录验证 print/JSON 或最小 SDK 路径，再进入 TUI。
6. 真模型实验另行说明案例数、调用次数、Token/费用范围后执行；不得继承个人目录内的账号配置来“顺手跑通”。
