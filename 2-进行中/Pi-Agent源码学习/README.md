# Pi Agent 源码学习

## 你接下来要做什么

先看 [Pi 整体框架与最小复现边界](资料/05-Pi整体框架与最小复现边界.md)：知道 Pi 是什么、优势与代价、一般 Agent 怎样运行、Pi 怎样组织这些职责，以及我们为什么只复现核心闭环。用户明确要求先建立整体框架；暂不要求运行代码练习。

主线依次是：整体框架 → 无代码走完一个具体任务 → 对照关键源码职责 → Python 单次工具执行 → Kimi 请求与核心循环 → 验收。JS/TS 只在读对应源码时按需解释。

最终产物：一个使用 Kimi、read 工具、非流式请求、内存消息历史和基本错误/停止处理的最小命令行 Agent。建议总预算 6–8 小时，包含缓冲；其他工具、流式、持久化和界面保留为选学。具体课时与细化范围为 AI 建议。
