## 记录方式

记录服务于交流与回看，形式随讨论自然调整。

- 每次有实质内容时维护记录，覆盖所有讨论话题；简短补充可以并入已有话题，不强制每轮新建文件，也不打断交流。
- 保留用户原意、关键原话、发散联想、Codex 的补充和质疑，以及观点之间的联系。事实、假设与不同判断清楚区分；转写纠正和观点变化以补充说明保留，不静默改写历史。
- 索引用来找回话题。恢复旧议题时查看对应记录，不凭印象补全，不强求形成统一结论。
- 不将讨论内容自动提取为待办、优先级、进度或检查日期，也不因想法尚不明确而把它送入任务清单。只有用户另外明确提出规划或执行需求时，才另行处理。
- 调研依据随需要保存到 `资料/` 或直接链接来源；与已有主题有关时建立关联，帮助后续联想与回看。
