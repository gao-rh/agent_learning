## 简历的判断目标

围绕目标岗位呈现真实职责、个人动作和可追问证据。Data 与 Agent 方向可以调整定位和篇幅，但不能为了拉开差异扩写未经确认的经历；明确限定的小改动不触发整份简历重写。

## 当前视觉基线

- A4 两页、单栏、现代藏蓝；正文深色，灰色只用于日期与辅助信息。
- 姓名与联系方式构成简洁页首；不使用页面顶部藏蓝横条，也不使用姓名左侧的藏蓝竖条。
- 保留章节标题的藏蓝色锚点与浅色分隔线，它们用于快速扫描。
- 项目标题行采用“项目名｜角色居中｜日期右对齐”；角色必须视觉居中，不只是文本居中属性。
- 不缩小正文字号强压一页；优先调节段间距、项目间距和分页断点。
- 当前中文字体使用 Hiragino Sans GB W3/W6；如果更换字体，正文、加粗、PDF 嵌入和跨端渲染必须一起验证。
- 页脚只保留姓名与页码，不放文件名、简历方向或版本号；版本号放在文件名中。

## 小版本 DOCX 处理

小改动优先在已验收 DOCX 上使用文档工具保留样式编辑。[version_resume_docx.py](../scripts/version_resume_docx.py) 是旧版辅助脚本，要求文档 XML 中实际命中 `--from-version`；当前 V1.x 页脚不含版本号，使用前须确认输入符合前提，不得为适配脚本把版本号加回页脚。其他参数见 `--help`，跨 Word run 的替换需检查完整句子。

## PDF 与预览生成

```bash
/Users/gaoronghui/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3.12 \
  .agents/skills/resume-builder/scripts/render_resume.py \
  --docx output/docx/高荣徽-Agent简历-VX.Y.docx \
  --pdf output/pdf/高荣徽-Agent简历-VX.Y.pdf \
  --preview-dir output/resume-preview-Agent-VX.Y
```

运行时使用当前环境可用的 Python 与文档工具；示例路径失效时重新定位依赖。[render_resume.py](../scripts/render_resume.py) 显式配置 macOS 字体目录以避免中文缺字，会清空指定预览目录再生成，因此该目录必须专用于本轮预览。渲染结果仍需按 SKILL.md 逐页验收。
