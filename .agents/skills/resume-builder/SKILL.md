# 简历生成与验收

先读[简历基线与工具](references/data-agent-resume.md)，定位用户要修改的方向、当前主编辑稿和最近确认记录。Word / PDF 编辑与渲染使用环境中对应的文档技能。

- 事实来源按用户近期确认、项目终稿或运行记录、原始材料、旧简历与 AI 草稿排序；数字或职责存在冲突时指出冲突，不用更好看的版本替代。
- 汇总本轮全部已确认修改，以当前主编辑 Markdown 为文本源；完整替换段落按用户确认原文落实，避免漏掉同轮较早要求。已授权的修改无需再次确认。
- 保留上一版本，同步主编辑稿和版本稿；从最近内容及版式验收通过的 DOCX 派生，只修改本轮要求的方向和内容。
- 逐项核对本轮变更在 Markdown、DOCX、PDF 中一致，替换位置无旧文案残留，并核对全文、日期、指标及论文作者，避免新旧稿混用。
- 用 [render_resume.py](scripts/render_resume.py) 导出 PDF 和逐页 PNG。必须逐页检查中文缺字、换行、对齐、分页和留白；检查 DOCX 完整可打开，PDF 满足参考文件中的版式与页脚要求。
