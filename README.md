# Agent Learning

这是一个以学习为核心的个人仓库，保存学习历史、重要资料、未来事项，以及学习相关的人生规划、课外阅读和小探索。

根目录按 `1 → 5` 排序。日常主要使用前三个状态入口；`4-学习资料` 是待拆临时区，不是新的分类体系。

| 入口 | 用途 |
| --- | --- |
| [清单](1-清单/README.md) | 尚未开始、仍需判断或已经确认的事项 |
| [进行中](2-进行中/README.md) | 当前真正投入时间的学习、规划、阅读、探索和工作主题 |
| [已完成](3-已完成/README.md) | 仍有价值的完整学习历史和成果 |
| [学习资料（待拆）](4-学习资料/README.md) | 暂存暂时无法明确归属的混合大资料；不接收新资料 |
| [归档](5-归档/README.md) | 失效制度、未确认 AI 草案、放弃事项和旧版本 |

每个正式主题只有一个 `README.md` 入口，下面按需放 `记录/`、`资料/` 和 `实验/`。重要资料应当能从根 README 进入主题，再从主题 README 直接打开。
