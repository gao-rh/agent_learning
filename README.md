# Agent Learning

这是一个以学习为核心的个人仓库，保存学习历史、重要资料、未来事项，以及学习相关的人生规划、课外阅读和小探索。

日常只需要从四个入口进入：

| 入口 | 用途 |
| --- | --- |
| [清单](清单/README.md) | 尚未开始、仍需判断或已经确认的事项 |
| [进行中](进行中/README.md) | 当前真正投入时间的学习、规划、阅读、探索和工作主题 |
| [已完成](已完成/README.md) | 仍有价值的完整学习历史和成果 |
| [归档](归档/README.md) | 失效制度、未确认 AI 草案、放弃事项和旧版本 |

每个正式主题只有一个 `README.md` 入口，下面按需放 `记录/`、`资料/` 和 `实验/`。重要资料应当能从根 README 进入主题，再从主题 README 直接打开。
