# 计算机网络核心课程笔记

[返回学习资料](../README.md)

## 当前目标

以软件开发和求职为目标，先建立一条主线：

> **一个应用发出的数据，怎样经过操作系统、协议栈和网络设备，到达另一台主机上的应用。**

操作系统前置知识已经足够。网络作为当前主线，遇到 Socket、缓冲区、epoll、NAPI 和零拷贝时再回看操作系统实现。

## 第一轮学习顺序

| 顺序 | 主题 | 学完后应该能回答 |
| --- | --- | --- |
| 1 | TCP/IP 分层与封装 | 每层解决什么问题？数据发送时每层添加什么信息？ |
| 2 | 以太网、MAC 与 ARP | 局域网中如何找到下一跳？知道 IP 后为什么还需要 MAC？ |
| 3 | IP、子网与路由 | 主机怎样判断直接发送还是交给网关？路由表做什么？ |
| 4 | UDP 与 TCP | 两者在连接、可靠性、顺序、开销和场景上有什么差别？ |
| 5 | TCP 可靠传输 | 握手、序号、确认、重传、流量控制和拥塞控制分别解决什么？ |
| 6 | DNS、HTTP 与 HTTPS | 输入 URL 后，DNS、TCP、TLS 和 HTTP 各做了什么？ |
| 7 | Socket 与本机观察 | IP、端口、TCP 连接、Socket 和 fd 怎样串起来？ |

## 学习原则

1. 先问“这一层解决什么问题”，再记字段和报文格式。
2. 每个协议都放回一次完整请求链路里理解。
3. 先能通俗解释，再补异常场景和性能细节。
4. 每学完一部分，脱离资料画图或口述，不把“看懂”当作“掌握”。

## 现在开始

第一步只学习 TCP/IP 分层与封装，并追踪一个问题：**浏览器发出的数据如何变成网卡发出的帧？**
