# 2026-08-07 Agent 岗位增量

## 本轮结论

- 本轮新增：6 条；要求变化：2 条；关闭：0 条。
- 新增分类：P0 1 条，P1 4 条，P2 1 条。
- 变化分类：P0 1 条，P1 1 条，P2 0 条。
- 最高优先新增：腾讯 WXG/小程序「微信小程序-AI Agent 开发工程师-小工具」，官网未写固定年限，直接负责 Agent 开发框架、Multi-Agent 分布式架构、沙箱/云环境、消息链路、数据存储和训练基础设施，是本轮最接近 Agent 后端/Runtime 主线的新岗。
- 第二优先新增：腾讯 CSIG/腾讯云「企业智能体-全栈开发工程师-WorkBuddy」，覆盖 Managed Agents 的编排、运行、治理、评测、Runtime、沙箱隔离、MCP/A2A/ACP 与工程 Harness，年限为 3 年以上。
- 本轮是当月第一个周五，全量覆盖 29 家；除腾讯官方 API 外，多数官网只能确认入口可达或返回动态壳页/404，未据此关闭任何旧岗位。
- 官网搜索命中数不解释为 HC；本轮明确招聘人数无新增可靠证据。

## 本轮要求变化

1. 微信小程序把 Agent 招聘拆成“工程框架”和“Coding Agent 算法”两条线：工程侧要求 Multi-Agent 分布式架构、沙箱/云环境、消息链路、数据存储和训练基础设施；算法侧要求需求建模、任务规划、记忆管理、自动化评测、回归验证和 Agent RL。
2. 腾讯云 WorkBuddy/CodeBuddy 继续强化 Managed Agents：从应用开发扩展到企业托管智能体的编排、运行、治理、评测、Agent Runtime、沙箱隔离、多租户和 OpenTelemetry Trace。
3. 混元 Harness 更新到 2026-08-06，仍强调 tracing、observability、eval pipeline、A/B、regression、debugging，以及对 Cursor / Claude Code / Codex 等 agentic coding failure mode 的体感。
4. AIOps、广告数据产品、视频号直播等新增说明 Agent 正继续向运维、营销数据和内容创作生产链路渗透；其中数据产品 Agent 只列 P2 兜底，不改变直接 Agent 后端优先级。
