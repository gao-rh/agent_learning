## 本轮要求变化

1. 腾讯 WXG 继续把 Agent 后端、工作流、多轮决策、Skill、RAG、Function Calling 与高并发后端写进同一个工程岗位画像。
2. 游戏 Agent 与企业微信多智能体是本轮新增最清晰的业务场景，说明 Agent 不只集中在通用办公或云平台。
3. Harness、Benchmark、沙盒、环境平台和数据集可追踪性继续成为独立工程岗位，和后端/平台能力强相关。
4. P2 只新增 1 条「Agent 数据与环境平台」，用于观察数据背景如何迁移到 Agent Eval/环境链路，不改变主投方向。
