# 计算机网络核心疑问总结

[返回学习资料](../../../4-学习资料/README.md)

当前还没有正式开始网络第一轮，先保留操作系统学习阶段已经出现的三个关键问题。后续学习中的核心疑问继续追加到这里，完整讨论留在内部过程记录。

| 核心疑问 | 当前结论 |
| --- | --- |
| Socket 到底是接口、系统、软件、协议还是结构？ | 最准确的第一层理解是“内核中的通信端点对象”。Socket API 是操作它的接口，fd 是应用持有的编号，TCP/UDP 是它可使用的传输层协议。 |
| NAPI 为什么比纯中断更好？ | 它在低流量时用中断，在高流量时批量轮询，减少中断风暴、重复调度和上下文切换；轮询仍占 CPU，但单位数据包的处理开销更低。 |
| 操作系统和计算机网络应该先学哪个？ | 不需要把操作系统全部学完。掌握进程、内存、fd、Socket、缓冲区和基本 I/O 后即可学网络；遇到实现细节再同步回补。 |
