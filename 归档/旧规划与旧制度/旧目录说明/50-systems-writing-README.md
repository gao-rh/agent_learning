# 写作方法

这个目录用于沉淀长期可复用的写作方法。

这里不放一次性的文章草稿，而放可以反复使用的原则、结构、检查清单和个人偏好。

## 当前方法

| 方法 | 用途 |
| --- | --- |
| [知识分享文档写作方法](知识分享文档写作方法.md) | 写概念解释、课程分享、技术理解类长文。 |
| [个人语言风格](个人语言风格.md) | 约束分享文档的语气、句式、表达禁区和个人偏好。 |

## 维护原则

- 每次写完一篇重要分享后，回看哪些结构有效、哪些语言别扭。
- 把可复用的经验沉淀到这里，不把一次性内容塞进方法文档。
- 方法文档要能指导下一篇文章，而不是只复盘上一篇文章。
