## 不计入规划文档的边界

以下内容即使出现“下一步”或 Todo，也不因此整份算作规划文档：

- 课程学习过程和实验准备记录；
- 概念笔记、调研报告和代码实验 README；
- 岗位索引、增量周报和纯资料索引；
- 根 README 和各目录 README 中的使用说明。

这些文档可以在归档时保留；如果用户希望将“含任何历史 Todo 的文档”也一并归档，需再扩大口径。

## 归档决策栏

归档前由用户在这里确认：

- [ ] A 类 5 份是否全部归档。
- [ ] B 类中哪些仍需保留为项目/仓库说明。
- [ ] C 类模板和空白日卡是否一并归档。
- [ ] D 类复盘是作为历史证据保留原位，还是放入历史归档。
- [ ] PDF 的两组重复位置保留哪一组。

在这些决定完成前，不开始新的 2–3 个月规划，也不从旧草案中继承目标、节奏或日程。
