## 已有记录

| 类别 | 当前记录 | 边界 |
| --- | --- | --- |
| 用户规模 | 约 20–30 名场景险产运与商分用户；高频主要为商分和少数资深业务 | 覆盖人数不等于 DAU / WAU |
| 普通使用 | 普通业务更常用于取数，深度分析相对较少 | 是用户确认的使用分布，不是埋点统计 |
| 分析使用 | 常规经营分析、开放式经营分析、异动分析和对话追问 | 不同用户的使用深度有差异 |
| 主动交付 | 每日定时分析流量和资源位，识别异常并通过大象主动推送简易报告 | 告警阈值与数量会根据业务反馈调整 |
| 周会链路 | Agent 自动生成周报和初步分析；管理者追问时，运营再向 Agent 查数 / 分析并将回答用于讨论或汇报 | 回答可能直接进入管理讨论，因此准确性和证据展示尤其重要 |
| 看数时效 | 传统流程至少等待半天，Agent 让用户可自助完成 | 未给出统一的系统耗时，不写成秒级 |
| 常规分析 | 从 2–3 天缩短到约 1–2 小时 | 只限常规专题，不代表所有开放分析 |
| 个人职责 | Agent 技术框架主负责人，联合业务、产品、商分和数据团队共建 | 不表述为独立完成整个项目 |
