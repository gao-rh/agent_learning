## 记录规则

1. 当前只按主题分类、按时间追加，不主动重组、压缩或补全内容。
2. 用户的原始表述保留在对应记录中；只做不改变含义的排版。
3. 新内容与旧内容一致时继续追加；若存在口径、层级、范围或结论冲突，保留所有版本，标记为“冲突待确认”，并向用户集中确认。
4. 只有用户明确要求“整理”并对冲突给出最终结论后，才派生稳定的最终材料。
5. 本目录内容不自动视为项目已实施、已验证或已最终确认的事实。
