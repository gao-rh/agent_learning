原则：

- 移动前后用路径、大小和校验值核对。
- 原文移动不改写；必要的链接更新单独记录。
- 大于 5 MiB 或尚未下载的文件只记录路径、大小和下载状态，不在本轮强制读取内容。
- `.git/`、迁移前损坏 Git 目录和运行时临时目录不属于学习历史清单。
