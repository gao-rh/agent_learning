#### 智能经营分析 Agent｜Agent 技术负责人

建设面向场景险业务的智能经营分析 Agent，为业务人员提供自助、高效、可信的取数、分析与主动告警能力。周活跃用户 30 余人，将报告类任务由 2～3 天缩短至约 2 小时，经业务估算每月节省约 23 人日，推动经营分析从有限人工响应转向业务自助，提升分析覆盖度与决策响应效率。

- **Agent 架构与编排：**基于公司内部模型、指标平台及通用工具接口，使用 Python 完成 Agent 应用层代码，构建由主 Agent 动态编排澄清、取数和报告 Agent 的多 Agent 协作体系；自主开发相关 Tool、Skill、缓存、评测脚本和定时任务，形成“澄清—执行—验证”的完整链路。
- **可信取数与评测：**将自然语言诉求收敛为标准指标及结构化查询参数，通过指标支持边界、交互式澄清、规则校验与按需复查构建可控问数链路；建设约 200 道业务问题的自动化回归评测集，在指标平台覆盖范围内，指标名称与数值问答准确率接近 100%，单轮任务成功率达到 83%。
- **记忆管理与知识库构建：**按用户与 Task 组织长期记忆，支持个性化分析、跨会话任务续接和历史经验复用；围绕数据知识、分析方法与业务知识搭建分层知识库，将商分与业务经验转化为可组合的分析 Skill。
- **知识治理与分析校验：**采用“结构化知识 + 全量原始知识”的分层管理方式，通过总结 Agent 预处理和人工确认沉淀业务事件、业务动作、场景—分析方法映射及指标参考范围；报告生成后校验指标适用性与数值合理性，异常时触发二次查询复核。
- **查询性能与预计算：**根据数据规模和时效设计分级缓存，对聚合结果进行复用，对长周期明细采用“历史全量 + 每日增量”更新；将典型复杂查询的端到端耗时由 30～60 分钟降至缓存命中后的数分钟，并将约 1 小时的异常分析转为后台预计算，使业务查看时可直接获取结果。

#### 理赔客服智能质检 Agent｜技术负责人

面向理赔客服通话中的人身攻击、辱骂及严重服务态度问题，建设日均约 1 万条通话的智能质检 Agent，将质检覆盖率由约 5% 提升至 100%，释放 1 名专业质检员人力；周均人工确认严重违规问题暂按由 2～3 条提升至 7～10 条记录，投递前根据同口径原始数据复核。

- **智能质检与分级复核：**设计“关键词预筛—角色校验—违规初审—脱敏—外部模型复核—人工确认”的分层链路。内部模型先判断客服与用户标签是否正确，错标时通过 Python 脚本交换角色，再进行违规初筛；脱敏后由外部模型完成逻辑复核与 A/B/C 分级，最终交由专业质检员确认。
- **小样本评测与迭代：**在初始仅有约 20～30 条违规样本、随机抽检阳性率约 1‰ 的情况下，以召回优先策略快速上线；将质检员复核结果持续沉淀为评测样本，结合证据输出、Few-shot 和 badcase 分析迭代 Prompt、分级标准与模型路由，形成“Agent 筛查—人工确认—样本回流—评测优化”的闭环。
- **工程实现与交付：**使用 Python 并依托公司内部低代码 Agent 平台完成项目应用代码、Prompt 和工作流配置，支持离线批量质检及线上按需调用；公司平台提供运行环境与模型能力，个人负责质检业务链路的设计、实现和持续优化。
